# MCP3208 Examples

- `read_voltage`: host-runnable introduction to raw, normalized, and millivolt reads
- RP2350 hardware examples live in the `rp2350-examples` package.

Read the host example first if you want to understand the MCP3208 frame format.
Read the first RP2350 example when you are ready to wire a real ADC, then use
the scan-all example to validate a fully populated analog front-end.
